# MOQSA: interfaz compatible con la APK original

Este módulo solo compila la clase MejoradoInicio y no incorpora el APK original, contraseñas, backend SOAP ni servicios Vercel.

El artefacto se utiliza para extraer el código de la pantalla de inicio. El empaquetado se hace localmente sobre la APK aportada por el usuario, sin subir sus credenciales a GitHub.

La pantalla enlaza las actividades originales para horarios, paradas y favoritos. El mapa complementario usa OpenStreetMap; el mapa Google original podría no funcionar tras cambiar el certificado.
